# Yit Desktop Fold 原生版

这是一个单进程的 .NET 8 WPF 桌面整理工具，不包含 Electron、Chromium、WebView、广告或网络服务。它可以在桌面上放置多个彼此独立的轻量整理块。

## 使用方式

- 用户桌面与公共桌面目录是真实数据源；整理块会自动镜像其中的文件、文件夹和快捷方式。
- 把桌面项目拖入另一个整理块只会改变分类和顺序，不会复制、移动或改写真实文件。块间拖动同样只更新元数据。
- Explorer 原生桌面图标、摆放坐标和选择交互始终保留；整理块作为额外的分类镜像与原桌面共存，文件仍原样保留在 Windows 桌面目录中。
- 单击高清应用图标直接使用 Windows Shell 启动。
- Shell 位图中偶发的低透明度方形画布残留会被精确清理；同一异常画布内过量的透明留白也会自动收紧，使实际图案与其他图标保持接近的视觉大小。正常图标边缘、留白和阴影保持不变。
- 鼠标点击图标不会残留包围图标的焦点框；使用键盘 Tab 导航时只显示一条短而中性的底部提示。
- 拖动图标之间的空白区域移动整理块。
- 悬停后拖动右下角两条轻量斜线调整大小；透明热区没有外围底板或轮廓。整理块最低可压至 120 DIP 的单图标行，图标网格会自动重排。
- 整理块最窄保留一个完整图标单元：大图标 114 DIP、中图标 94 DIP、小图标和列表 76 DIP；切换并保存更大的布局时，过窄的块会扩展到对应下限。120 DIP 最小高度不变。
- 每个整理块可在设置的“当前整理块”中独立选择大、中、小或列表四种固定布局。调整整理块尺寸只改变行列数量，不会连续缩放图标；列表固定为单列并显示名称，切回网格后仍保留原来的“显示图标名称”偏好。
- 图标行默认从整理块左侧内边距开始排列，右侧有剩余空间时也不会把整组图标强制居中。
- 当固定尺寸的图标超出整理块高度时，可直接在块内使用鼠标滚轮或触控板平滑上下浏览；内容始终裁剪在块内，不显示常驻滚动条。
- 整理块固定在桌面底层：点击图标、拖动、缩放或从托盘恢复时都不会抢走普通窗口焦点，也不会覆盖普通应用。
- 桌面壁纸空白处仍使用 Explorer 原生框选。整理块中的命中状态会在拖动过程中实时更新，可跨块选择；框选缩小或移开时立即取消对应选择。按住 Ctrl 可追加选择，单击空白处清除，选择状态不会写入配置。
- 按 `Win+D` 或点击任务栏最右侧显示桌面时，程序会识别 Windows 11 24H2 的 `Progman` 桌面层及旧版 Windows 的 `WorkerW` 桌面层，并直接响应 Explorer 的桌面重排事件，在同一合成帧内保持整理块位于桌面图标宿主之上，不再出现先消失再恢复的闪烁；普通应用重新出现后，整理块会立即回到其后方。
- 需要纯键盘操作时，可按 `Ctrl+Alt+D`（或使用托盘中的“键盘操作模式”）进入最近使用的整理块：Tab 选择、Enter 启动、Alt+方向键移动，Escape 退出并恢复之前的前台窗口。
- 移动整理块并松手时保留原有的边缘、对齐线和 10 px 间距位置吸附，且不会改变块的尺寸。拖动右下角期间宽高完全自由；松手时会选择上方、左侧或右侧空间上最近且对齐的相邻块，接近其宽度或高度时分别用短暂平滑过渡匹配。未接近的尺寸保持松手时的值，也不会出现文字、增亮或脉冲提示。关闭磁吸后两种吸附都不触发。
- 右键图标可将项目移回默认整理块；真实桌面项目的位置不会变化。
- 右键整理块可新建更多整理块、重命名并打开“外观与吸附…”。文件夹名称、图标名称和“隐藏边框和背景”开关不放在右键菜单中，而位于设置窗口的“当前整理块”区域。纯图标模式会使用 Windows 11 的逐像素透明合成，关闭当前块的底板、系统边框、矩形阴影、圆角轮廓、边缘响应、名称与缩放标记，仅保留高清图标，不会退化成白色底板；透明空白区域仍支持拖动、右键和缩放，关闭后恢复此前保存的名称偏好与平滑圆角。图标名称与图标之间保留轻微间距并以单行省略显示，布局过密时会暂时隐藏文字以保持图标清晰。
- 独立的自绘设置窗口包含全局外观、“当前整理块”和“隐藏整理块”三部分。背景透明度可在 0–100% 间拖动、直接输入或使用 −/+ 微调；毛玻璃使用固定的轻量系统效果，可独立开关，并可选择黑色或白色底色。全局外观会在同一帧同步到全部整理块，名称开关只预览和保存到当前整理块；取消、Escape 或关闭设置都会回滚尚未保存的这两类设置草稿。高缩放或矮屏幕下主体可滚动而底部操作始终可见；设置与自绘提示在打开期间会显示于任务栏，切换应用后也能找回。
- 当背景透明度达到 92% 以上时，整理块会根据所在位置的桌面明暗自动选择浅色或深色名称与控制标记，避免文字融入壁纸。
- “隐藏整理块”会实时逐项列出当前运行期已经隐藏的块，可只恢复其中任意一个。恢复立即生效，不参与外观设置的保存或取消回滚，也不会重置其位置、尺寸、名称、快捷方式内容或显示偏好。
- 整理块的位置、尺寸、图标布局、文件夹/图标名称显示状态、纯图标模式和各自内容会按块独立保存，下次启动原位恢复。隐藏仅作用于当前运行期，不会跨启动保持。
- 所有确认、警告和重命名提示均使用独立的全局自绘烟灰弹窗，不再嵌入或裁剪在整理块内部；系统文件选择器仍使用 Windows 原生选择器。
- 右键文件夹底可设置登录时启动、隐藏或退出。即使全部整理块都已隐藏，也可从系统托盘打开设置并逐项恢复，或双击托盘图标一次恢复全部整理块。

## 数据安全

- 程序只扫描用户桌面和公共桌面根目录来建立只读目录快照；日常分类、排序和删除整理块都不执行文件移动或复制。
- 每个项目优先使用卷序列号与文件 ID 作为稳定身份，因此外部重命名后仍可保留原分类；目录监听器会合并短时间内的变更并实时同步新增、删除和重命名。
- 多整理块状态使用临时文件后原子替换，并保留上一份备份。旧版 `%LocalAppData%\YitDesktopFold\Shortcuts` 内容只在首次升级时事务性迁回真实桌面；状态提交失败会回滚迁移动作。
- 配置损坏时会保留损坏文件；若检测到旧版管理目录中的孤立快捷方式，会先安全恢复到桌面再建立分类引用。
- 配置目录或开机启动注册表暂时不可读时会安全降级并给出保存反馈，不会因策略权限异常直接退出；共享图标缓存使用 96 项 LRU 上限，移除快捷方式或整理块时会立即清理不再使用的缓存，避免长期增删不同内容后持续增长。
- 托盘和多显示器工作区直接使用 Win32 API，不加载 Windows Forms 或 System.Drawing UI 框架；每个快捷方式只实例化当前“大/中/小/列表”布局实际需要的一套视觉元素，隐藏布局不再常驻内存。

## 构建

```powershell
dotnet build .\native\YitDesktopFold.Native.csproj -c Release
dotnet run --project .\native.tests\YitDesktopFold.Native.Tests.csproj -c Release
dotnet publish .\native\YitDesktopFold.Native.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=false -p:DebugType=None -p:DebugSymbols=false
```

发布版保留为少量框架依赖文件。桌面项目内容不再占用应用数据空间，状态目录只保存分类、顺序、位置和外观元数据。程序依赖系统共享的 Microsoft .NET 8 Desktop Runtime；它可由所有 .NET 桌面应用共同使用，不属于本程序的独占文件。正式对外分发前还应补充代码签名；未签名程序可能触发 SmartScreen 提示。
