# YitDesktopFold 0.1.0

首个公开的 Windows x64 早期版本。

## 主要内容

- 原生桌面层多整理块，支持 `Win+D` 与 Explorer 原生桌面共存。
- 普通桌面项目和回收站等虚拟项目双向归类，不移动真实文件。
- 大、中、小、列表四种固定布局，以及滚动、纯图标、透明度、玻璃和黑/白底色设置。
- Windows 11 风格紧凑项目菜单、完整 Shell 菜单和特殊回收站操作。
- “登录 Windows 时启动”迁入独立设置窗口，保存后事务性生效。
- 自包含单文件应用与每用户安装器，无需预装 .NET Desktop Runtime。

## 已验证

- 自动化测试覆盖分类/恢复、虚拟图标拖放、旧状态迁移、设置草稿、固定布局与磁吸几何。
- Windows x64 静默安装、文件版本检查与静默卸载通过。
- 自包含安装器大小：66,742,641 bytes（63.65 MiB）。
- SHA-256：`D692FC6F73DDFE93A44C8F43CD22B6FFBE45C1EED162E322AF2EC375231E3D0A`
- 临时安装文件占用约 72.7 MiB；隔离空白桌面 15 秒样本为 113.2 MiB 私有内存、209.9 MiB 工作集与 2.05 秒累计 CPU。

## 注意

此版本尚未进行 Authenticode 代码签名，Windows SmartScreen 可能显示未知发布者。请从本仓库 Release 下载并核对 SHA-256。
