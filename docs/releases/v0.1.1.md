# YitDesktopFold 0.1.1

Windows x64 早期版本的首个补丁更新。

## 主要变化

- 每个整理块按稳定显示器身份保存独立的比例位置和尺寸。
- 显示器临时断开时安全回退，重新连接后恢复原布局，不用临时坐标覆盖显示器档案。
- 设置窗口的隐藏整理块列表支持逐个显示或删除；删除会恢复项目的原生桌面可见性，不移动真实文件。
- 整理块和快捷方式右键菜单在点击菜单外区域时立即关闭。

## 兼容与数据

- 状态格式升级为 Schema 5，现有 Schema 4 配置会保留原坐标，并在首次保存时建立当前显示器档案。
- 安装器继续按当前用户安装，不要求管理员权限，也不清理用户配置。
- 本版本仍未进行 Authenticode 代码签名，Windows SmartScreen 可能显示未知发布者。
