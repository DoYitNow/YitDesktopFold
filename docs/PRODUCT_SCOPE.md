# 产品边界与腾讯桌面整理对比

## 参考范围

腾讯桌面整理（DeskGo）公开介绍中常见的能力包括：按类型自动整理、自定义格子、展开/收起、锁定、文件夹映射、全局搜索、最近文档、便签与壁纸。参考：

- [腾讯桌面整理工具功能介绍（腾讯云开发者社区）](https://cloud.tencent.com/developer/article/2243858)
- [桌面整理工具历史介绍（腾讯云开发者社区）](https://developer.cloud.tencent.com/article/1684135)

这些页面包含不同年份的产品描述和历史资源数据，只用于功能范围参考，不作为当前版本性能基准。

## 本项目的取舍

| 能力 | YitDesktopFold 0.1.0 | 取舍原因 |
| --- | --- | --- |
| 多格子/自定义尺寸 | 已实现 | 桌面收纳的核心工作流 |
| 桌面与格子双向拖放 | 已实现 | 分类只改元数据，不搬动真实文件 |
| Explorer 原生图标共存 | 已实现 | 未归类项目继续使用原生位置、框选和菜单 |
| 固定图标布局与滚动 | 已实现 | 尺寸变化不扭曲图标，紧凑块仍可浏览 |
| 展开/收起标题栏 | 不采用 | 既定视觉不使用外部标题、工具栏或展开面板 |
| 自动按类型接管桌面 | 不采用 | 明确分类更可控，避免意外隐藏或重排用户项目 |
| 锁定位置/尺寸 | 候选 | 对防误触有价值，后续应放在设置中且不增加块内工具栏 |
| 映射已有目录 | 候选 | 必须是对现有目录的显式视图，不创建替代快捷方式或搬运文件 |
| 全局搜索/最近文档 | 不计划 | 会引入索引、历史记录和更多常驻资源 |
| 便签、壁纸、云服务 | 不计划 | 与轻量桌面收纳目标无关 |

## 当前差异化

- 桌面目录是唯一真实数据源，分类状态可逆且带原始可见性所有权记录。
- `Win+D`、Windows 11 24H2/旧版 Explorer 层级、原生壁纸框选与第三方 Shell 菜单扩展共同工作。
- 普通文件系统项目和回收站等虚拟 Shell 项目采用各自正确的拖放与菜单路径。
- 没有账号、网络、广告、遥测或内容中心；后台工作限制在桌面根目录观察与低频桌面层恢复。

## 资源基线

0.1.0 自包含 x64 安装器为 63.65 MiB，临时安装后的文件占用约 72.7 MiB。在隔离的空白桌面与新配置中运行 15 秒的一次样本为：私有内存 113.2 MiB、工作集 209.9 MiB、933 个句柄、累计 CPU 2.05 秒。

该样本用于说明 .NET/WPF、DWM 和 Shell 集成的当前基线，不是长时间泄漏结论，也不等同于每台机器的稳定值。当前实现通过单进程、按需布局模板、96 项 LRU 图标缓存、桌面根层监听和低频恢复计时器限制增长。显著降低框架基线需要迁移到更底层的 Win32/DirectComposition UI，属于独立架构项目，不应在保持现有视觉和交互的补丁发布中仓促进行。
